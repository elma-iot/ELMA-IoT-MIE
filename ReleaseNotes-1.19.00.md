# MIE 1.19.00 — inspection evidence and Item View

Portable review candidate in the 1.19 series. The owner has deferred version 2.0.0 until the remaining fixes are complete. This version has not been submitted to Microsoft Store.

The attached-documents list and Save a copy action are now at the bottom of the left Item View pane. The right pane is primarily for document and 3D preview. Version labels retain the requested `1.19.00` format, and cached 2.0 prototype pack descriptors are replaced with compatible 1.19.00 descriptors.

- Returned Inventory equipment awaiting assessment also appears in the Quarantine worklist as the same physical item. Its Inventory tip opens the matching assessment record.
- **Review inspection** records Pass/Fail, inspection notes, supporting documents, applicable tests and named approval. Submit releases the item to service or approves it for scrap. Approval for scrap does not claim that disposal has happened. Inspection, testing, repair and approval requirements remain enforced.
- PDF, Word, Excel and scanned-photo evidence stays inside the project. Lifecycle history retains the documents and decision details. Incremental native saves, backup, synchronization and project merges reuse unchanged content; identical bytes are stored once. A submitted review has one Undo/Redo step.
- The print button exports the currently displayed Item View (including its scene and section) to PDF or Excel. PDF is a static view. With compatible installed desktop Excel, an additional worksheet embeds the original GLB as a rotatable native 3D object. The displayed section remains on the first sheet. Item View is excluded from File **Save project as XLSX**.
- Licensed **View item** context actions open the new **Item View** workspace. The left pane shows equipment information/status; the right pane lists attachments, previews them and offers Upload documents and Save a copy. In-Order records and historical equipment can retain documents too.
- PDF preview loads one page at a time in an isolated worker. Word previews show read-only text, Excel previews show cached worksheet values, and photos use bounded decoding. Legacy DOC/XLS preview requires the corresponding installed Office application. Original attachments remain available through Save a copy. These are document previews, not full Office layout/editors.
- GLB scenes and their controls remain in the separate, verified optional viewer pack. The native scene uses the SWIMS inventory viewer's studio/control conventions: damped orbiting, automatic rotation, Home, a view cube, six camera presets, a larger view, material/color controls, lighting and a generated 1.2 × 0.8 m EUR pallet reference. Hidden scenes stop their timers.
- **Cut view** starts at the model center. Select **X, Y or Z**, drag the colored scene grip, adjust the position slider or use the focused grip's arrow keys. **Center section** resets the plane; Reverse cut side swaps the retained side. Hide the translucent guide independently of the section. Geometry work runs in a cancellable background task and leaves the original model intact.
- Closed section faces use dashed hatching with different orientations per mesh part. Even-odd tessellation preserves cavities and concave outlines. Open/non-manifold boundaries stay unfilled. Parts must exist as distinct meshes in the uploaded model to receive distinct hatch patterns.
- Model metalness, roughness and emissive color now affect lighting correctly within the native renderer's limits. WPF uses its hardware-eligible Direct3D path; this review PC reported graphics tier 2. Native materials approximate glTF PBR: environment-map, normal-map and ray-traced reflections are not implemented. Five scene/background/floor/pallet colors are exposed in Theme Studio.
- When GitHub cannot be reached, **Browse pack…** accepts the required pack from the PC. Exact approved size and SHA-256 are checked before atomic installation. A bad selection cannot replace a working pack. Background 3D download failures offer the browse button without interrupting other work. Store executable modules remain part of the reviewed package.
- PN/SN parsing preserves entered suffix zeros and manufacturer suffixes. **View → Normalize displayed PN / SN** is disabled by default. Enabling it changes presentation only; editors and Excel retain the entered identifiers, and duplicate checks continue using canonical keys. Digits already removed from previously saved data cannot be reconstructed automatically.
- Guide, synthetic Item View tutorial and interface catalogs cover all 20 application languages. Updated scenes and controls are included in the on-demand pack rather than the main executable.

Verification includes offline local-pack import and corruption rejection; identifier save/reopen and Excel preservation; inspection release/rejection, evidence bytes, Undo/Redo, incremental saving, backup and merge; licensed/free Item View access; document/GLB preview; X/Y/Z clipping in both directions; hollow/concave hatch tessellation; direct grip movement and UI responsiveness; light/material response and rendering tier; existing lifecycle, clipboard, Excel and theme checks; and translated tutorial playback. Synthetic test projects were used for the new features.
