# MIE 1.19.15 — visible license role

About and Help > License activation now show the active licensed role and every assigned department scope. The information updates when a license or interface language changes. Older licenses display “Legacy license (no assigned role)”; the application does not assume Full Control. Free or inactive licensing displays “Free edition (no licensed role)”. An older license needs a new unlock key issued with an explicit role to participate in protected-project editing.

The shared presentation follows the current theme and includes translations for all 20 languages, with built-in fallback labels for older cached packs. Role UI and backend checks pass, including live role changes, department scopes, legacy/free labels, protected projects and the existing 219 permission assertions.

Application, owner tool and Store package version: 1.19.15. Microsoft Store submission remains on hold for owner testing.
