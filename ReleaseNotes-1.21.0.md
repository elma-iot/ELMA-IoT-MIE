# MIE 1.21.0

- Save organization-encrypted projects to a local working store. Reopen the project from Recent Projects, or export a portable archive for transfer.
- Synchronize committed revisions through a shared Windows folder. MIE reuses verified files and transfers changed or missing objects. Keep browsing, editing and saving during the exchange. Newer pending work is preserved when applying an incoming revision must wait.
- Follow overall and per-step progress. Use **Full Sync / Repair** in the sync window to verify both project copies and recover missing or damaged files from a verified copy. Genuine conflicts still open for review.
- Small Inventory comment updates refresh their affected rows. Independent drawing and model edits can merge more quickly. Administrators can review storage, retired payloads and recovery options under **File → Project recovery**.
- Review upcoming and overdue inspections, print inspection reports with evidence and serial-specific model views, and look up weight and description information from technical references.
- Manage Storage areas and their equipment lists with multiselection. Configure how equipment fits on its pallet and reuse the configuration for future placements where applicable.
- The interface, guide and updated synchronization walkthrough are available in all 20 supported languages. **Help → Packs** installs reviewed downloads for offline reuse.

Existing managed projects can continue with their current files and sync setup. Administrators upgrading a legacy organization server folder can follow the shared-folder upgrade steps in the guide.
