# Licensed roles and protected projects

Free users can continue editing ordinary free projects. A restricted licensed user can open a free or unprotected database for viewing only and receives a notice. A user with an active Full Control role must review the database and choose File > Save as protected MIE project to create a protected copy. The original file is retained. Protected copies require MIE 1.19.14 or later and are read-only in the free edition. Protection includes a signed Full Control enrollment and signed saved content; changing the data or merely adding a protection flag is not accepted. Unprotected or differently protected copies cannot enter protected synchronization. Full Control may explicitly review a project import.

Keygen offers Full Control, Manager / Approver, Engineer / Data Editor, Maintenance Technician / Inspector and View Only. Managers and Engineers receive Equipment / Operations, Maintenance and/or Planning scopes. Roles and scopes are included in the owner-signed unlock key. A new license request includes the public authorization key for this Windows account. Keep its protected authorization-key.dat file with the application data; its private key is never sent to the owner. Older unlock keys retain legacy permissions on ordinary projects; they cannot authorize protected project edits. New role keys are rejected by older clients. Equipment Engineers enter equipment details, link schematics, receive and transfer equipment. Planning Engineers edit orders, quantities, suppliers, dates and lead times; Planning Managers additionally define minimum stock and planning policies. Maintenance Technicians and Maintenance Engineers submit inspections, test results and supporting documents. Submission alone does not make stock available. Maintenance Managers review submitted evidence and explicitly approve release or scrap. Applicable passed tests, repair completion and physical return remain required. A file attachment alone is not a passed test. Another Maintenance Manager must approve the same person’s inspection; Full Control retains administrative authority. Scrap approval and completed disposal remain separate actions. View Only can browse, search, inspect history, print and export, without changing data or uploading evidence. Menus, right-click actions, toolbars, shortcuts, paste, replace and Undo/Redo follow the role and current project protection. Already-open windows refresh after a license change. Audit records retain the licensed actor and role at the time of the action. The guide filters editing topics and offers a role-based walkthrough for restricted roles. Language, guide and game packs remain general content available to every role. Licensed 3D viewing remains available; damage paint, deformation, reset, texture uploads and model Undo/Redo follow editing permissions. Normal navigation, section viewing and exports remain available in read-only use. Role protection enforces permissions in supported MIE clients and detects unauthorized changes to protected files. Licenses are offline: an older valid key remains usable until expiry; changing roles does not revoke previously issued keys. Use individual Windows accounts and separate portable application folders for different people; a shared Windows login shares its authorization key. Keep the authorization-key.dat file with application data when moving a portable installation. It is not a server account system and does not prevent a Windows administrator from replacing software or using other tools. A copied or reconstructed unprotected database still requires Full Control review before restricted licensed users can edit it. Keep backups and control access to shared folders and owner signing keys.
