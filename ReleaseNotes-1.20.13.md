# MIE 1.20.13

## Inventory and the 3D Map

Click a row number to follow equipment across a wide table. For repeated serials, follow the duplicate link or open the Inventory duplicate list for printing or export. Column visibility is specific to this computer and carries through to Excel exports.

In the 3D Map, right-click the visible deck, pallet, equipment, terrain or open water to see the actions available there. A vessel’s tooltip shows its task, normal sailing speed and ETA. The ship slider accelerates playback. The camera speed control adjusts navigation independently.

## Updating model libraries

Use **Add 3D model** to replace a part’s primary model. Use **Upload** in Attached documents to keep an alternate GLB. The placement dialog offers a model choice when distinct versions exist.

For a folder import, **Accept all** processes compatible replacements and pauses for a substantially different model. Choose whether to accept or reject that replacement, then select **Continue**. **Finish review later** preserves the queue. The **Resume review** badge shows the outstanding count.

## Help and settings

The user guide and guided tutorials cover cargo placement, quarantine and scrap areas, vessel operation, container loading, map lighting, duplicate review, idle saving and model replacement. The interface and learning packs cover 20 languages. Open Help to read the guide in your selected language. [User guide](UserGuide.txt)

In File → Settings, you can enable background 3D preloading and choose the automatic save interval. Preloading starts disabled. The default automatic save interval is 30 minutes and saves pending changes when the computer is idle.
