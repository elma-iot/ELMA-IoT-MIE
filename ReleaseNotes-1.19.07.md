# MIE 1.19.07 - 3D viewer controls review

The optional 3D pack restores the complete textured mesh when Cut view is disabled. Cut faces are plain solid surfaces without pattern lines or a plane outline; cavities remain open. A shaded double-headed arrow follows the selected section axis and supports dragging and keyboard fine adjustment.

Settings, Home and Large View are tooltip-labelled icons aligned with Reset view. The translucent bracketed view overlay offers perspective, true orthographic projection and six standard directions. Pointer is the default tool. Damage-marking and deformation buttons sit below the view cube; their disclosure arrows open the relevant translucent Spot/Circle or Raise/Lower controls, including size, softness, thickness, color, strength and viewer history.

Camera projection is remembered per item/model alongside existing scene settings. Both projections support pointer-centred zoom, model picking, marks and section manipulation. Reference geometry remains anchored to model bounds during camera panning. Rendering, tools and processing stay in the separately verified 3D pack; the application only hosts its toolbar.

Updated guide, tutorials and all 20 language catalogs. Validation covers solid section caps/cavities, repeated cut restoration with textures, perspective/orthographic zoom, toolbar docking, damage/deformation/history and PDF/Excel Item View exports. The Windows test system uses WPF rendering tier 2; per-vendor hardware performance is not claimed.

Portable test build: `build/MIE Portable.exe`. Restart MIE to load the new verified pack. Public content is published as `mie-content-v45`, with Browse pack fallback. The Microsoft Store candidate is prepared locally and held; no Partner Center upload or submission is authorized yet.
