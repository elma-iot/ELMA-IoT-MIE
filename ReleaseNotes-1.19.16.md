# MIE 1.19.16 — 3D badges, viewer fixes and header appearance

Prepared 6 November 2026. Application and Microsoft Store package versions: **1.19.16** and **1.19.16.0**.

P/N cells with an available attached GLB model display a small blue ice cube at the top-right corner. Its vertices rotate clockwise around the cube's central, upright Z axis once every 24 seconds and are projected through a fixed oblique camera. This is vector drawing with changing face widths and depth, rather than a rotating flat icon.

The badge has 50% opacity, glass-like face shading and theme-aware contrasting edges. It contributes no width or height to the cell, does not shift the original content, and does not intercept mouse input. Hidden or unloaded badges stop animating. The existing shared-P/N model library supplies the availability lookup, including older attachments and normalized part numbers, without loading the viewer or modifying project data.

Model badges now refresh dynamically after attachments are added during the current session. Retained table columns receive the latest shared-P/N model index, and existing badges observe index changes even when the P/N text and row object remain unchanged. Previously opened hidden tabs update when revisited; matching equipment shares the badge while unrelated part numbers stay unmarked. The integration check uploads a model for H57720-102 through a background workbook transaction in a single app instance.

Supported P/N listings include installed equipment, Inventory, Quarantine, In-Order, minimum stock, schedule requirements and procurement, lifecycle history and the minimum-stock recommendation preview. Editing, clipboard values and Excel data exports retain the original identifiers without badges.

The candidate also includes the pending minimum-stock policy fix: a policy with a zero minimum can be removed without deleting equipment from Inventory. Explicit exclusions survive save/reopen and prevent automatic rediscovery. Undo/Redo and explicit Add restore the policy as expected; positive minima must be set to zero first.

The viewer also fixes transparent model rendering. Solid geometry, including dials and decals, is drawn before clear covers, and transparent parts are ordered back-to-front for the current camera. H57720-101 now shows its yellow graduated target beneath the ball without altering the source GLB. Nested transforms, original geometry, painting identities and section geometry are preserved.

Navigate, damage-marking and deformation tools now sit in the top toolbar immediately left of Home. A rightmost pallet button toggles the existing Standard EUR pallet setting and stays synchronized with Settings. Wood grain follows each plank's longest dimension using a consistent physical UV scale, including thin sides.

Help > About now centers the icon, title, attribution and license/role text; the GitHub link remains left-aligned. An explicitly licensed Full Control user can choose a local SVG or PNG through Help > Application header icon. The header image preserves alpha, fits the header height and updates immediately. The default icon is unchanged until a custom choice is made. Other roles and legacy/free licenses cannot change the setting. Expiry, missing licensing or loss of Full Control restores the default display through normal license notifications, retaining the saved choice for later reactivation. Window, taskbar and About icons, application text and project branding are unaffected.

The guide, tutorial captions and all 20 translations cover every missing change since the previous v53 content update: badges and live attachment refresh, transparent dials, relocated viewer tools, the pallet toggle and wood mapping, zero-minimum policy removal, centered About, and header customization. Four new guided examples use generated models and temporary workspaces. All 80 language/topic combinations pass real-control navigation and original-project preservation checks. The offline UserGuide.txt and both language resource packs are regenerated. A stale About/countdown explanation is corrected.

Viewer module 1.19.16 and the new language/learning ZIPs are approved by exact digests compiled into the app, using the existing signed v53 baseline catalog. No project format or minimum reader version change is introduced. All three new download assets are staged under Optional Content v54 and must be published at their pinned URLs before distributing the slim portable ZIP. The unpacked review app includes the complete offline cache; the Store MSIX bundles the updated viewer and retains optional data downloads. No content upload or Store submission has been performed.
