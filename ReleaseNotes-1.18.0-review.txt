ELMA-IoT MIE 1.18.0 review — equipment movement and active-tab printing

Right-click an installed equipment cell for Sent to Inventory. Choose a linked equipment group, select another existing group, or enter a new title. The installed cell is cleared and the item returns to its Inventory group, unavailable pending assessment and release.

Inventory right-click actions include Add to Well and Send to Quarantine. Add to Well selects an existing well and equipment column. Both dialogs have Remove from Inventory, unticked by default. Unticked keeps a linked register row at the well or in Quarantine; ticked removes the Inventory listing while preserving the current equipment record and history. Quarantined links are orange and unavailable. Inventory links are projections of the same identity, not extra physical stock.

Non-disposed Quarantine equipment can be sent back to Inventory through its right-click menu. It leaves Quarantine but stays unavailable. Release to Service still separately requires the existing inspection/test evidence and named approval. Scrap approval remains separate from completed disposal; disposed items are audit-only.

Moves check normalized PN and usable SN. An existing matching destination listing is updated rather than duplicated. Different parts sharing a serial, multiple ambiguous matches, stale source data and a different occupied well cell are rejected for review. Blank serials do not identify the same unit. Consolidation of pre-existing duplicate identities preserves explicit history and prevents an older sync copy from silently restoring the retired record. Group links follow renames and are retained through native exchanges.

After successful moves in each direction, the application switches to the destination tab, scrolls to the row, selects it and briefly fades the row into focus. Actions run through the existing background transaction, Undo/Redo, revision, lifecycle and synchronization components.

The header printer icon, File > Print and Ctrl+P open the active tab's print/export window, including detached tabs. Choose printer output, Save as PDF or Extract to Excel. Preview provides portrait/landscape, A4/A3/Letter/Legal, margins, fit-width, fit-to-one-page, custom percentage scaling and zoom. Windows printer selection, copies and page range are confirmed through the standard print dialog, then queued asynchronously. PDF destinations are explicit and replacement requires confirmation. Printer output retains vector text; PDF reuses the existing 300-DPI image-PDF writer. Excel extraction reuses the existing exporter for only the opened worksheet, or only the selected schematic. Library extraction is an illustration metadata table. Metrics uses its numeric report; planning Timeline/Procurement uses the existing corresponding Excel report. The project-wide XLSX action is unchanged.

Linked Inventory rows are marked in Excel exports and skipped as physical entries on reimport, preventing double counting. Existing licensing and encryption rules are unchanged; no RBAC, database or KeyGen changes. Older projects remain readable. Files using the new retained-register or identity-consolidation workflow require MIE 1.18.0 or newer so older peers cannot drop the new semantics.

Twenty-language interface, guide and synthetic tutorial packs are updated in public content v31. Both new tutorials were exercised in all twenty languages and restore the original project. Synthetic checks cover all movement directions, both removal choices, focus, group creation, duplicate consolidation, stale-sync protection, native save/reopen, Excel projection roundtrip, PDF output, orientation/scaling, active-tab-only XLSX, lifecycle approvals/disposal, encrypted saves, transfers, clean startup and empty-project opening. No operational project data is included or modified. A physical printer job was not sent during testing.

This is a review release for testing; it has not been submitted to Microsoft Store. Windows 10/11 with .NET Framework 4.8. Extract and run MIE Portable.exe.
