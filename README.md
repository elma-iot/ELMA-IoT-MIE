# ELMA-IoT MIE

![ELMA-IoT MIE application icon](assets/mie.png)

**MIE Portable** is a Windows desktop application and part of the [ELMA-IoT project](https://github.com/elma-iot). It brings a master equipment list, linked schematics, and a reusable illustration library into one portable workspace.

## Application overview

- **Master Equip. list** — browse imported equipment tables, search records and open linked schematics.
- **Schematics** — view native Excel-rendered drawings and PDF references, including grouped vector illustrations.
- **Illustration Library** — identify reusable illustrations while keeping each occurrence's scale, dimensions, rotation and flips.
- **File, View and Help** menus — create/open/save projects, import files or a folder, and access the embedded user guide.
- **Save project as XLSX** — recover a master workbook and an accompanying Schematics folder for editing in Excel.
- **Portable startup** — one EXE can prepare its local working files while displaying the ELMA-IoT animated logo.

Native XLSX schematics retain their original editable drawing objects. PDF-origin schematics can be packaged in clearly labelled image-based reference workbooks, with their original PDFs preserved alongside them.

## Requirements

Windows 10/11 and .NET Framework 4.8. Microsoft Excel is needed on the importing PC for XLSX schematic rendering. Viewing saved projects and exporting their original workbook contents do not require Excel. The application uses no macros.

## Repository scope
